# Bear mascot assets

The current transparent PNG mascot family was generated for Life Lately's visual refresh:

- `bear-default.png` - waving journal companion
- `bear-writing.png` - entry editor companion
- `bear-empty.png` - empty journal state
- `bear-search.png` - no search results
- `bear-celebrate.png` - streaks, calendar, and insights
- `bear-sleeping.png` - appearance and night-theme settings

Keep these filenames when replacing artwork so FXML references do not need to change.
